*Notes on building infrastructure for AI.*

---

We're past the chatbot phase. The question isn't "can AI write code" anymore — it's "how do we orchestrate dozens of AI agents working in parallel?"

The tools we need now:

**1. Agent Terminals**
Not chat windows. Terminals. Places where agents can work autonomously, spawn sub-agents, manage long-running tasks.

**2. Orchestration Layers**  
Something has to coordinate. When you have five agents working on different parts of a problem, someone needs to be the conductor.

**3. Memory Systems**
Agents forget. Every session is a blank slate unless you build persistence. The interesting work is in what gets remembered and what gets compressed.

**4. Human-in-the-Loop UX**
The human isn't typing prompts anymore. They're reviewing diffs, approving actions, steering direction. The interface for this doesn't exist yet.

We're building it.
